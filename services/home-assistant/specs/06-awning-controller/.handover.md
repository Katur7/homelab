# Technical Handover: Somfy Soliris + Shelly Plus 2PM & Add-on Integration

**Target Audience:** Development Agent for Shelly mJS scripting & Home Assistant automations

**Objective:** Replace a decommissioned Somfy Soliris Uno controller with a **Shelly Plus 2PM** and **Shelly Plus Add-on** to handle manual wall switching, automated sun-based awning deployment, and local wind-safety retraction.

---

## 1. System Architecture & Hardware Overview

* **Main Controller:** Shelly Plus 2PM (Firmware: Gen2 / Gen3, Profile: `Cover`)
* **Sensor Adapter:** Shelly Plus Add-on (mounted directly to the Plus 2PM)
* **Wall Switch:** Schneider Exxact Jalusibrytare (shutter switch with mechanical interlock)
* **Sensors:** Somfy Soliris combination sensor (3-wire passive unit: Common, Sun, Wind)
* **Motor:** Standard 230V AC 4-wire tubular motor (Earth, Neutral, Direction 1 / Up, Direction 2 / Down)

```
       +------------------------------------+
       |       Schneider Exxact Switch      |
       |  L: Phase | ▲: Up (S1) | ▼: Dn (S2)|
       +------------------+-----------------+
                          | 230V (FK 1.5mm²)
+-------------------------v----------------------------+
|                  Shelly Plus 2PM                     |
|  Power: L (Brown), N (Blue)                          |
|  Inputs: S1 (Up), S2 (Down)                          |
|  Outputs: O1 (Motor Up/Retract), O2 (Motor Down/Ext) |
+-------------------------+----------------------------+
                          | Internal Bus
+-------------------------v----------------------------+
|                Shelly Plus Add-on                    |
|  GND: Somfy Common (C)                               |
|  Analog In + Vref+R1 Out jumper: Somfy Sun wire      |
|  Digital In: Somfy Wind wire (Reed pulse to GND)     |
+------------------------------------------------------+

```

## 2. Physical Wiring & Pin Assignments

### A. 230V Mains & Motor Side (1.5 mm² / FK 1.5)

* **Schneider Jalusibrytare:**
* `L`: 230V Permanent Phase (Brown).
* `▲` (Up arrow): Switched Phase to Shelly **`S1`** (Brown wire, labeled `UP`).
* `▼` (Down arrow): Switched Phase to Shelly **`S2`** (Brown wire, labeled `DOWN`).
* `X`: Unused pass-through terminals.


* **Shelly Plus 2PM:**
* `L` terminals: 230V Phase (Brown).
* `N` terminal: 230V Neutral (Blue).
* `O1`: Retract / UP winding of the awning motor.
* `O2`: Extend / DOWN winding of the awning motor.



### B. Low-Voltage Sensor Side (Somfy 3-Wire Cable)

* **Common (`C`) Wire:** Connected to **`GND`** on the Add-on (serves as the common reference for both sun and wind circuits).
* **Sun Sensor Wire (Variable Resistance Photo-Element):**
* Connected to **`Analog in`**.
* **Hardware Jumper:** A link wire (Yellow/Orange) is installed between **`Analog in`** and **`Vref + R1 out`**. This enables the internal reference resistor to create a voltage divider, translating light levels into a 0–3.3V / 0–100% analog signal.


* **Wind Sensor Wire (Mechanical Dry-Contact Reed Switch):**
* Connected to **`Digital in`**.
* The internal 3.3V pull-up holds the line high; the spinning anemometer magnet pulls `Digital in` directly to `GND` once or twice per revolution.

## 3. Sensor Signal Specifications

| Sensor | Physical Principle | Shelly Interface | Electrical Behavior |
| --- | --- | --- | --- |
| **Sun** | Photoresistor (LDR) | Add-on `Analog In` (`input:101` or `volts`) | High light $\rightarrow$ Lower resistance / higher voltage drop. Dark $\rightarrow$ High resistance. |
| **Wind** | Reed switch pulse generator | Add-on `Digital In` (`input:100`) | Measured with multimeter: toggles between Open Circuit ($OL$) and Closed Circuit ($\sim 0\,\Omega$). Frequency scales directly with wind speed (10–30+ Hz in heavy wind). |

## 4. Required Implementation Tasks

### Task 1: Shelly Plus 2PM Base Configuration

1. **Device Profile:** Set to `Cover`.
2. **Input Type:** Configure `S1` and `S2` as **Dual button** or **Dual switch** (depending on whether the Schneider rocker is momentary push or maintained click).
3. **Movement & Dead-time:** Ensure motor direction dead-time protection is enabled so `O1` and `O2` can never engage simultaneously.
4. **Calibration:** Run the automatic limit calibration cycle once connected to the motor.

---

### Task 2: Local mJS Scripting for Wind Safety (Critical)

Because an awning can suffer structural damage in high winds, **retraction must NOT rely exclusively on Wi-Fi or Home Assistant availability**. An mJS script must run locally on the Shelly.

#### Script Requirements:

* Listen to state transitions on the Add-on's digital input component (`input:100`).
* Accumulate pulse counts over a sliding evaluation window (e.g., $1500\text{ ms} - 2000\text{ ms}$).
* If `pulseCount >= WIND_THRESHOLD`, issue an immediate `Cover.Close` (or `Cover.Open`, depending on which direction corresponds to retraction in the calibrated profile) call.
* Enforce a temporary safety lockout (e.g., block auto-extension for 15–20 minutes after a wind trigger).
* **Reference Prototype:**

```javascript
// Shelly Plus mJS Wind Protection Monitor
let pulseCount = 0;
let WIND_TRIGGER_PULSES = 10;   // Calibrate based on physical spin test
let CHECK_INTERVAL_MS = 2000;    // Evaluation window
let LOCKOUT_TIME_MS = 900000;    // 15-minute wind lockout
let isLocked = false;

Shelly.addEventHandler(function (event) {
  // Capture rising/falling transitions on digital input
  if (event.component === "input:100" && event.info && event.info.state === true) {
    pulseCount++;
  }
});

Timer.set(CHECK_INTERVAL_MS, true, function () {
  if (pulseCount >= WIND_TRIGGER_PULSES) {
    print("WARNING: Wind safety trip! Pulses counted:", pulseCount);
    // Retract awning immediately (id: 0)
    Shelly.call("Cover.Close", { id: 0 });
    
    // Set safety lockout
    isLocked = true;
    Timer.set(LOCKOUT_TIME_MS, false, function () {
      isLocked = false;
      print("Wind safety lockout expired.");
    });
  }
  pulseCount = 0;
});

```

### Task 3: Home Assistant Automations (Comfort & Sunlight Logic)

Home Assistant should oversee comfort automation while respecting the Shelly's onboard safety state.

#### Entities to Target:

* `cover.awning` (Shelly Plus 2PM Cover entity)
* `sensor.awning_sun_sensor` (Add-on Analog input voltage or percentage)
* `binary_sensor.awning_wind_pulse` (Add-on Digital input state)

#### Automation Logic:

1. **Sunny Day Auto-Extend:**
* **Trigger:** `sensor.awning_sun_sensor` > threshold for $\ge 10\text{ minutes}$.
* **Conditions:**
* Awning is currently closed.
* No recent wind events / wind lockout helper is `off`.
* Time of day is between specified morning and late afternoon hours.
* Local weather forecast does not forecast rain or high gusts.


* **Action:** Call `cover.open_cover` (or set position to desired %).


2. **Low-Light / Evening Auto-Retract:**
* **Trigger:** `sensor.awning_sun_sensor` < threshold for $\ge 20\text{ minutes}$ OR Sun set.
* **Action:** Call `cover.close_cover`.


3. **Manual Override State:**
* If a manual press on `S1`/`S2` closes the awning during peak sun, create a helper (`input_boolean.awning_manual_override`) to prevent the sun automation from immediately re-extending the awning. Reset the override at midnight or upon manual reopen.
